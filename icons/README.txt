Свои иконки оружия для килл-листа.

Имя файла = ID оружия SA-MP, формат PNG с прозрачным фоном,
белая иконка, высота ~64 px. Примеры:
  0.png  - кулак
  24.png - Desert Eagle
  25.png, 26.png, 27.png - дробовики
  30.png, 31.png - автоматы
  33.png - Rifle
  34.png - снайперская винтовка

Если файла для оружия нет, показывается встроенная иконка.
Используйте только иконки, на которые у вас есть права.
